# Changelog

## 1.0.0 – 18 November 2026

First public version.

- A desktop for every address on the site: menu bar, control strip, draggable windows and icons, with a phone layout.
- Folders from Portfolio project types, files from projects, documents from pages, notes from posts.
- Document viewer for PDFs, shortcut files for links, a mail-style contact window and a music player for YouTube links.
- Paint, Mines, Solitaire, a sliding puzzle and a terminal.
- For the logged-in owner: write, edit, rename, upload and delete from the desktop itself.
- Sounds made by the browser, with a mute button. Reduced-motion and keyboard support.
